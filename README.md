# Engine Resiliente de Automações

Sistema de cadastro de candidatos com disparo assíncrono e resiliente de automações (retry com exponential backoff), dashboard em tempo real e reprocessamento manual.

> Documentação completa de setup (variáveis de ambiente, instalação, execução) será adicionada ao final do desenvolvimento.

## Estrutura

```
backend/    API REST (Node.js + TypeScript + Express + Prisma/SQLite)
frontend/   Dashboard (React + TypeScript)
```
